# Telemetria v2: posição e rota

A v2 acrescenta `navigation` ao [contrato v1](README.md). O transporte,
os eventos e o limite de 4096 bytes por frame, sem LF, permanecem iguais.
O modelo é `FrameV2` em [`modelos.py`](../../src/telemetria/telemetria/modelos.py),
com schema em [`v2.schema.json`](v2.schema.json).

O receptor aceita v1 e v2. Para emitir a extensão, passe `schema_version=2`
ao `TelemetryPublisher`. Atualize o receptor antes do firmware, pois receptores
v1 rejeitam a versão 2. Comandos e ACK continuam na versão 1.

## Campos

`navigation` pode acompanhar qualquer evento e exige `maze_id` quando não nulo.

| Campo | Conteúdo |
| --- | --- |
| `width`, `height` | Dimensões inteiras do labirinto, de 1 a 32 |
| `pose` | `{x, y, heading, source}` ou `null` |
| `route` | `{source, cells: [{x, y}, ...]}` ou `null` |

Ao menos `pose` ou `route` deve ser não nulo. As coordenadas são índices de
células dentro das dimensões informadas. A origem `(0,0)` fica no canto inferior
esquerdo; x cresce para leste e y para norte. Quando `map` e `navigation`
aparecem juntos, suas dimensões devem coincidir.

`heading` usa `N`, `E`, `S` e `W`. Na FW11, converta o índice da orientação com
`("N", "E", "S", "W")[pose.heading]`.

`source` usa `simulated`, `measured` ou `estimated`. Posição calculada por
odometria ou movimentos confirmados e rota calculada pelo planejador usam
`estimated`. Dados de simulação usam `simulated`.

A rota contém as células na ordem de execução, incluindo início e destino.
Células consecutivas precisam compartilhar uma face. Se a pose acompanhar uma
rota não vazia, a primeira célula deve coincidir com ela. A rota representa o
plano, não o percurso já realizado; pode atravessar regiões ainda desconhecidas.

`route.cells=[]` limpa a rota anterior. Campo omitido ou `null` significa sem
atualização. Consumidores que acumulam snapshots devem guardar o tempo de cada
informação e limpar os dados ao trocar boot, corrida ou labirinto.

A rota aceita até 1024 células, respeitando o limite de bytes do frame inteiro.
Se não couber, o emissor retorna `False` e conta a perda, sem truncar a rota.
Envie pose e rota separadas das leituras ou paredes quando necessário.

## Uso

```python
publisher = TelemetryPublisher(
    robot_id, boot_id, run_id, maze_id, clock_ms, schema_version=2,
)
publisher.sample("executando", navigation={
    "width": 4,
    "height": 4,
    "pose": {"x": 0, "y": 0, "heading": "N", "source": "estimated"},
    "route": {
        "source": "estimated",
        "cells": [{"x": 0, "y": 0}, {"x": 0, "y": 1}, {"x": 1, "y": 1}],
    },
})
```

O laço continua chamando `service()` com o mesmo orçamento de escrita.
Republicar snapshots permite recuperar dados perdidos. Captura e reprodução
preservam a navegação; o painel atual não desenha esses campos.

Exemplos: [`v2.validos.jsonl`](v2.validos.jsonl) e
[`v2.invalidos.json`](v2.invalidos.json). Para regenerar os schemas e testar:
